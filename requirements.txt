# NIDS-PyTorch dependencies

# The four packages under "Core ML / data" are PINNED EXACTLY on purpose: the
# files in models/ are pickled (scaler.pkl, encoder.pkl) and torch-serialised

# release. Retrain the models if you bump these.
#
# Everything else is a runtime library that touches no serialised state, so a
# minimum-version floor is enough.
# =============================================================================
